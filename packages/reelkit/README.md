# reelkit

Native video playback manager for Flutter: bounded native player pool,
priority-based player reuse, typed errors and a rendering widget with full
`BoxFit`/`Alignment` support. You build the UI.

Development preview (milestone 4): the complete player API and the player
manager (pooling, exclusive playback, decoder-shortage handling) work on
Android, iOS and web; feed preloading and caching come in later milestones. See the [repository README](../../README.md) for usage,
platform support and status.
