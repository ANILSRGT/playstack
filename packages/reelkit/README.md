# reelkit

Native video playback manager for Flutter: bounded native player pool,
priority-based player reuse, typed errors and a rendering widget with full
`BoxFit`/`Alignment` support. You build the UI.

Development preview (milestone 5): the complete player API and the player
manager (pooling, exclusive playback, decoder-shortage handling) and the
feed manager with network- and memory-aware preloading work on
Android, iOS and web; caching, fullscreen and audio sessions come in later milestones. See the [repository README](../../README.md) for usage,
platform support and status.
